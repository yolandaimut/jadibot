Kebijakan Privasi Data (Privacy Policy)

Privasi dan keamanan kredensial operasional Anda merupakan prioritas inti dalam perancangan arsitektur Xu Core. Kebijakan Privasi ini menjelaskan secara transparan bagaimana kami mengumpulkan, menyimpan, mengisolasi, melindungi, dan menghapus data akun serta kredensial sesi otomatisi bot WhatsApp Anda di dalam infrastruktur server kami.

Zero Password Storage

Autentikasi 100% menggunakan Google OAuth 2.0 berbasis Google Sub ID tanpa pernah merekam kata sandi Anda.

Container Storage Isolation

Setiap kredensial sesi Baileys dipisahkan pada direktori khusus di dalam Secure Container Persistent Storage per akun.

Atomic Local Persistence

Data konfigurasi di database.json ditulis secara atomic untuk mencegah korupsi data.

01

Pengumpulan Data Login Berbasis Google OAuth & Google Sub ID

Untuk menghindari risiko kebocoran kredensial kata sandi tradisional, Xu Core tidak menyediakan formulir pendaftaran kata sandi konvensional. Seluruh proses masuk panel menggunakan verifikasi token kriptografi resmi dari Google Identity Services (Google OAuth 2.0).

  • Data Profil Minimum: Kami hanya menerima dan memproses informasi identitas dasar yang diberikan Google, meliputi pengenal unik akun (Google Sub ID), nama depan/tampilan, alamat email terverifikasi, dan tautan foto avatar profil.
  • Tanpa Penyimpanan Kata Sandi: Xu Core tidak pernah melihat, meminta, mencegat, atau merekam kata sandi akun Google Anda maupun kode PIN verifikasi dua langkah WhatsApp Anda.
  • Keamanan Cookie Sesi: Setelah token Google terverifikasi di sisi server, sistem menerbitkan cookie sesi bertanda tangan kriptografi (Signed Session Token) untuk memproteksi seluruh jalur HTTP dan koneksi WebSocket Socket.io Anda.
02

Pengamanan Kredensial Enkripsi Sesi WhatsApp (Baileys / Web)

Saat Anda menautkan akun WhatsApp melalui pemindaian Kode QR atau 8-Digit Phone Pairing, pustaka @whiskeysockets/baileys menghasilkan pasangan kunci enkripsi perangkat tertaut (Signal Protocol Noise Keys, Pre-Keys, dan identitas perangkat) yang disimpan ke berkas creds.json serta berkas kunci sesi terpisah.

  • Enkripsi Transport End-to-End: Komunikasi antara instance bot Xu Core dengan server WhatsApp tetap berjalan di atas protokol enkripsi ujung-ke-ujung (Signal Protocol) standar WhatsApp Multi-Device.
  • Pembatasan Akses Berkas Kredensial: Direktori penyimpanan sesi berada di luar folder publik web (public/), sehingga mustahil diakses secara langsung melalui peramban (browser) maupun permintaan HTTP eksternal.
  • Tanpa Penyimpanan Riwayat Chat Permanen: Pesan masuk hanya diproses di memori secara sementara (transient) untuk mengeksekusi perintah plugin, pencocokan auto-reply, dan menayangkan cuplikan ringkas pada RealTime CLI Terminal pribadi Anda (dibatasi maksimal 100 baris di memori sementara).
03

Isolasi Secure Container Persistent Storage (Anti-Kebocoran Data)

Infrastruktur Xu Core memanfaatkan Secure Container Persistent Storage yang terpasang secara persisten pada kontainer Docker di Infrastruktur Hosting/VPS kami. Untuk menjamin integritas lingkungan multi-penyewa (multi-tenant), kami menerapkan mekanisme isolasi berlapis:

  • Pemisahan Direktori & Metadata Kepemilikan: Setiap sesi bot ditempatkan dalam sub-direktori tersendiri pada Penyimpanan Server Terisolasi dan dilengkapi berkas metadata pemilik (.owner.json) yang diikat langsung ke Google Sub ID sah.
  • Ruang Socket Terisolasi (Room Isolation): Seluruh pembaruan status, QR Code, kode pairing, log terminal, dan statistik trafik dikirim secara eksklusif ke ruang WebSocket terisolasi (user_<googleId>), sehingga data antar pengguna tidak dapat saling melihat atau bocor.
  • Sanitasi Jalur Berkas: Nama direktori sesi dan pengenal akun selalu melalui sanitasi karakter ketat di sisi server guna mencegah celah manipulasi jalur direktori (path traversal).
04

Keamanan Berkas Local Session & Integritas database.json

Xu Core dirancang secara mandiri menggunakan sistem penyimpanan berkas lokal terproteksi (database.json) dan manajemen state lokal di dalam volume kontainer server, tanpa memaparkan data Anda ke server cache eksternal pihak ketiga yang terbuka.

  • Metode Atomic Write Anti-Corrupt: Setiap pembaruan konfigurasi bot, daftar jadwal pesan, dan metrik pesan ditulis terlebih dahulu ke berkas sementara terisolasi (.tmp) sebelum dipindahkan secara atomik ke database.json, menjaga keutuhan struktur data meski terjadi restart mendadak.
  • Enkripsi Volume di Tingkat Infrastruktur: Seluruh berkas local session, kunci Baileys, dan database.json yang tersimpan di dalam Penyimpanan Server Terisolasi dilindungi oleh lapisan enkripsi disk penyimpanan (encryption-at-rest) dari Infrastruktur Hosting/VPS serta akses berkas terbatas pada tingkat sistem operasi kontainer.
  • Pemisahan Hak Akses Administratif: Endpoint pencadangan arsip (/api/backup/download) dan editor plugin dikunci ketat melalui middleware verifikasi identitas admin utama di sisi server.
05

Hak Kendali Pengguna, Retensi & Penghapusan Permanen

Anda memegang kendali penuh atas kredensial sesi WhatsApp yang ditautkan pada platform Xu Core. Kami tidak pernah menjual, menyewakan, atau membagikan data pengguna maupun daftar kontak WhatsApp Anda kepada pihak ketiga mana pun untuk kepentingan pemasaran.

  • Penghapusan Sesi Instan: Anda dapat memutus koneksi bot dan menghapus seluruh folder kredensial sesi Baileys dari Penyimpanan Server Terisolasi kapan saja melalui tombol Hapus Sesi / Logout di dashboard. Sistem akan mengirim sinyal logout resmi ke WhatsApp lalu menghapus direktori sesi secara rekursif.
  • Pencabutan Akses dari Ponsel: Anda juga dapat mencabut tautan kapan saja langsung dari aplikasi WhatsApp di ponsel Anda melalui menu Perangkat Tertaut.
  • Permintaan Penghapusan Akun Penuh: Untuk permintaan penghapusan menyeluruh catatan Google Sub ID dari database.json, Anda dapat menghubungi Admin resmi Xu Core dengan menyertakan Google Sub ID akun Anda.
