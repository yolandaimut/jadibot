Buka Dashboard
Quick Start Guide Estimasi Waktu: 3 Menit

Panduan Langkah demi Langkah Pengguna Baru

Ikuti tahapan terstruktur berikut untuk memulai penggunaan panel Xu Core dari proses autentikasi pertama kali, penautan WhatsApp hingga status aktif Connected, perpanjangan masa aktif, sampai pengunduhan arsip cadangan platform (Backup ZIP).

01

Autentikasi Aman Tanpa Password

Login Pertama Kali Melalui Google Auth

  1. Buka halaman masuk resmi Xu Core pada alamat /login melalui peramban Chrome, Safari, atau Firefox versi terbaru.
  2. Klik tombol Sign in with Google dan pilih akun Google yang ingin Anda jadikan identitas utama pemilik bot.
  3. Sistem akan memverifikasi token identitas secara otomatis di server, menerbitkan cookie sesi terenkripsi, dan mengalihkan Anda ke halaman /dashboard.
  4. Setelah dashboard termuat, ruang Penyimpanan Server Terisolasi pribadi Anda serta catatan awal pada database.json otomatis terbentuk dengan pengenal unik Google Sub ID.
Catatan: Anda dapat menyalin Google Sub ID kapan saja dengan mengeklik foto avatar profil di pojok kanan atas navbar lalu memilih menu Salin Google Sub ID.
02

Penautan Perangkat WhatsApp

Memindai Kode QR Hingga Status Berubah Menjadi "Connected"

  1. Pada tab Dash, temukan kartu Status Koneksi & Profil di sisi kiri. Pastikan tab autentikasi berada pada mode QR Code Box.
  2. Klik tombol Generate / Refresh QR Code. Status akan berubah menjadi Connecting... dan gambar Kode QR akan muncul dalam beberapa detik.
  3. Buka aplikasi WhatsApp di ponsel Anda, masuk ke menu Setelan / Titik Tiga → Perangkat Tertaut → Tautkan Perangkat.
  4. Arahkan kamera ponsel ke Kode QR yang tampil di layar dashboard hingga pemindaian selesai.
  5. Tunggu 3–5 detik hingga sesi tersinkronisasi. Lencana status merah Disconnected akan berubah menjadi hijau Connected, kartu profil WhatsApp Anda muncul, dan tanda Server Container Auth Active menyala.

Alternatif Tanpa Kamera (Phone Pairing 8-Digit):

Jika Anda membuka dashboard dari ponsel yang sama dengan WhatsApp, pilih tab Phone Pairing, masukkan nomor internasional diawali kode negara (contoh: 6281234567890), lalu klik Request 8-Digit Pairing Code dan masukkan kode tersebut di menu Tautkan dengan nomor telepon pada WhatsApp.

03

Manajemen Langganan

Memperpanjang Masa Aktif Menggunakan Tombol "Perpanjang"

  1. Perhatikan strip informasi di bagian atas dashboard tepat di bawah navbar. Di sana tertera status sisa hari langganan Anda (misalnya Starter • 1 Slot • Sisa 3 Hari).
  2. Klik tombol Perpanjang yang berada tepat di samping indikator masa aktif tersebut.
  3. Jendela modal Perpanjang Masa Aktif Bot akan terbuka menampilkan paket aktif Anda saat ini beserta pilihan durasi (7 Hari, 30 Hari, atau 90 Hari). Untuk melihat paket khusus seperti Paket Elite 127 Hari, Anda juga dapat mengunjungi halaman Sewa/Beli Paket.
  4. Klik kartu durasi paket yang diinginkan. Browser akan otomatis membuka WhatsApp Admin Xu Core dengan format pesan yang sudah terisi nama paket dan Google Sub ID akun Anda secara akurat.
  5. Setelah konfirmasi pembayaran diverifikasi Admin, masa aktif akun Anda diperbarui secara langsung. Klik Sync Session pada menu dropdown profil untuk melihat pembaruan sisa hari secara instan.
04

Keamanan & Arsip Data (Akses Admin)

Mengunduh Cadangan Platform (Backup ZIP)

Untuk menjaga keamanan konfigurasi seluruh akun dan kode plugin sebelum melakukan pembaruan besar atau migrasi Infrastruktur Hosting/VPS, pengelola dengan hak akses Admin dapat mengunduh cadangan penuh platform dalam satu berkas arsip terkompresi (.zip):

  1. Pastikan Anda masuk ke dashboard menggunakan akun Admin resmi yang terverifikasi.
  2. Klik ikon Avatar Profil di pojok kanan atas navbar untuk membuka menu dropdown akun, lalu pilih tombol Backup ZIP.
  3. Sebagai alternatif, Anda juga dapat membuka tab IDE (Plugin IDE) pada navbar, lalu menekan tombol Backup ZIP di sudut kanan atas daftar plugin.
  4. Server akan mengemas berkas database.json beserta seluruh isi direktori plugins/ melalui endpoint /api/backup/download.
  5. Peramban Anda akan mengunduh berkas bernama jadibot-backup-YYYY-MM-DDTHH-MM-SS.zip secara otomatis. Simpan arsip ini pada penyimpanan luring (offline) atau cloud pribadi yang aman.
Informasi Akses: Demi melindungi isolasi privasi multi-pengguna, tombol dan endpoint Backup ZIP hanya tersedia bagi akun Admin platform. Pengguna reguler yang membutuhkan salinan data konfigurasi pribadinya dapat menghubungi Admin resmi melalui kontak WhatsApp.
