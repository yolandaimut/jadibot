Dokumentasi Teknis Platform Xu Core

Panduan referensi menyeluruh mengenai mekanisme kerja inti panel otomatisi Xu Core, pemetaan komponen dashboard, interpretasi log terminal langsung, pemantauan kesehatan sumber daya server, serta praktik terbaik melindungi nomor WhatsApp dari pembatasan otomatis.

1. Cara Kerja & Arsitektur Panel Xu Core

Xu Core dibangun di atas arsitektur backend Node.js (ECMAScript Modules) menggunakan Express.js untuk melayani antarmuka web serta Socket.io sebagai kanal komunikasi dua arah berlatensi rendah antara peramban Anda dan proses mesin bot.

Engine Baileys Multi-Device

Menghubungkan nomor WhatsApp langsung melalui WebSocket terenkripsi tanpa memerlukan peramban headless (Chromium/Puppeteer), sehingga konsumsi RAM jauh lebih efisien dan respon perintah berlangsung dalam hitungan milidetik.

Secure Container Persistent Storage & Atomic DB

Kredensial creds.json disimpan pada direktori sesi terpisah di Penyimpanan Server Terisolasi. Konfigurasi, metrik, dan jadwal disimpan ke database.json menggunakan atomic write untuk mencegah kerusakan berkas.

Boot Auto-Restore & Scheduler

Saat server dinyalakan ulang, Xu Core memindai seluruh sesi terdaftar secara bertahap (staggered boot) dan memulihkan koneksi otomatis, sementara worker latar belakang memeriksa jadwal pesan setiap 15 detik pada zona waktu WIB.

Autoreload Plugin Dinamis

Perubahan atau penambahan berkas modul perintah pada direktori plugins/ langsung divalidasi sintaksnya dan dimuat ulang secara langsung (hot-reload) tanpa memutus sesi WhatsApp yang sedang berjalan.

2. Penjelasan Struktur Menu Dashboard

Antarmuka dashboard Xu Core disusun secara modular agar seluruh operasional harian dapat diakses cepat dari perangkat desktop maupun mobile:

Tab Dash (Dashboard Utama)

Monitoring & Koneksi

Menampilkan kartu metrik real-time (Pesan Masuk, Pesan Terkirim, User Aktif, Bot Uptime), kartu Status Koneksi & Profil (QR Code, Phone Pairing, tombol Restart Koneksi, Hapus Sesi, toggle Auto Read & Public Mode), Top 5 Perintah Populer, grafik Request Velocity, grafik System CPU/RAM/Disk, grafik Trafik 7 Hari, dan RealTime CLI Terminal.

Tab Kelola (Manajemen & Otomatisi)

Konfigurasi Bot

Menyediakan formulir Konfigurasi Bot (Nama Bot, Nomor Owner Tambahan, Sticker Packname/Author, Filter Kata Terlarang, Auto-Reply mode exact|contains|starts, Mode Tanpa Prefix), modul Broadcast Grup Anti-Spam, Kirim Pesan Langsung (dengan opsi Mention All), Pesan Terjadwal & Reminder (Sekali/Harian/Interval), Katalog Fitur & Toggle Kategori, serta Manajemen User (termasuk pemisahan status Premium Reseller) & Grup Aktif.

Navbar Kanan: Pusat Notifikasi & Menu Akun

Utilitas & Akses

Ikon lonceng membuka Pusat Pemberitahuan & Notifikasi resmi sistem. Dropdown avatar profil menyediakan pintasan Salin Google Sub ID, Sync Session manual, aktivasi Alert Putus (Notifikasi Browser), pemilih tema aksen (Emerald, Cyan, Violet), tombol Backup ZIP & Panel Admin (khusus Admin), serta tombol Logout akun panel.

3. Cara Membaca Log Aktivitas Bot Secara Real-Time (CLI Terminal)

Panel RealTime CLI Terminal merekam setiap kejadian penting pada instance bot Anda secara langsung dengan penanda waktu WIB ([HH:MM:SS]). Gunakan tombol filter di atas jendela terminal untuk menyaring kategori pesan berikut:

Level FilterKode WarnaArti & Contoh Kejadian
INFOAbu-abu TerangInisialisasi koneksi Baileys, pemuatan QR Code, perubahan pengaturan toggle, dan dimulainya proses broadcast.
OK (SUCCESS)Hijau EmeraldBot berhasil tersambung (Connected as ...), kode pairing terbit, pesan langsung/jadwal terkirim, atau konfigurasi berhasil disimpan.
MSGBiru CyanLalu lintas pesan masuk ([IN]) maupun pesan keluar ([OUT]) lengkap dengan nomor pengirim dan cuplikan isi pesan.
WARNKuning AmberKoneksi terputus sementara (sedang mencoba reconnect), sesi dihapus, kategori fitur dinonaktifkan, atau jadwal pesan dihapus.
ERR (ERROR)Merah RoseMasa aktif habis, sesi logged out dari ponsel, kegagalan pengiriman pesan, atau error sintaks/runtime pada eksekusi plugin.

4. Manajemen Penggunaan Memori, CPU & Penyimpanan Server

Kartu REAL-TIME SYSTEM pada dashboard memancarkan telemetri kontainer setiap 1 detik dan memindai kapasitas Penyimpanan Server Terisolasi secara berkala setiap 15 detik untuk menjaga efisiensi komputasi:

  • Indikator RAM (RSS & Heap): Menampilkan total memori aktif proses Node.js dalam satuan MB. Arahkan kursor pada nilai RAM untuk melihat perbandingan Heap Used terhadap total memori OS kontainer. Untuk menjaga RAM tetap ringan, nonaktifkan kategori fitur media berat yang tidak digunakan pada tab Kelola → Katalog Fitur.
  • Indikator CPU & Request Velocity: Grafik detak jantung CPU (%) dan REQ/S membantu Anda mendeteksi lonjakan perintah mendadak atau grup yang melakukan spam perintah berulang.
  • Indikator DISK (Secure Container Persistent Storage): Menampilkan akumulasi ukuran seluruh berkas sesi dan database.json. Lakukan pembersihan pengumuman lama atau hapus entri user tidak aktif pada tab Manajemen User secara berkala agar ukuran database tetap ramping dan cepat dibaca.
  • Soft Restart Koneksi: Apabila respon bot melambat akibat antrean socket yang menumpuk, gunakan tombol Restart Koneksi alih-alih menghapus sesi. Tindakan ini menyegarkan instans socket Baileys tanpa mengharuskan Anda memindai ulang Kode QR.

5. Praktik Terbaik Mengamankan Nomor WhatsApp dari Pemblokiran

Sistem deteksi otomatis WhatsApp memantau pola pengiriman pesan yang tidak wajar. Terapkan konfigurasi berikut pada panel Xu Core untuk meminimalkan risiko pembatasan sementara maupun pemblokiran nomor:

1. Atur Jeda Broadcast 5–15 Detik

Hindari menggunakan jeda minimum 2 detik jika jumlah grup aktif Anda melebihi 15 grup. Gunakan interval 6 hingga 12 detik per grup agar ritme pengiriman menyerupai interaksi manusia normal.

2. Gunakan Variabel Dinamis Pesan

Sisipkan variabel {botName}, {date}, dan {time} pada pesan broadcast maupun jadwal rutin agar setiap pesan memiliki sidik teks yang berbeda.

3. Lakukan Pemanasan Nomor Baru

Jangan langsung menjalankan broadcast massal pada nomor WhatsApp yang baru didaftarkan. Gunakan nomor untuk percakapan dua arah secara alami minimal selama 7–14 hari sebelum diotomatisasi penuh.

4. Batasi Mention All & Filter Spam

Gunakan fitur Mention Semua Anggota Grup secara bijak hanya untuk pengumuman penting agar tidak memicu laporan (Report) dari anggota grup, serta manfaatkan fitur Ban Grup/User bagi pengirim spam perintah.
